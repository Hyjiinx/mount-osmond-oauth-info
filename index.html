Mount Osmond Golf Booking

This is a privately developed application for personal use by its owner. It helps identify potential golf booking opportunities based on the owner's Google Calendar schedule.

The application is not affiliated with, endorsed by, or operated by Mount Osmond Golf Club or Google.

The application uses Google OAuth to request access to the owner's Google Calendar. Access is granted only after the owner explicitly authorises it.

For information about how calendar data is handled, please read the Privacy Policy.
